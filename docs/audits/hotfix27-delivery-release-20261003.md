## Changes and invariants

120 seconds and enter a separately bounded warning view. Exact observed native
queue membership stays pending; original receipts and command observations
retain their meanings. Prepared/dispatched work, malformed/future clocks and
genuine ambiguity retain conservative handling. Age never proves consumption,
cancellation or failure. Both harnesses advertise the optional
`messages.deliveryWarnings` v1 capability.

Exact returned root history can repair display/consumption through the existing
single Host writer. Private facts are bounded to twice the requested page size,
atomically validated and stripped from the wire. Child/summary/omitted history,
text similarity and empty queues cannot certify consumption or repair a
lifecycle gap. Tracked commands and the latest 512 exact IDs are deduplicated so
repeated large pages stabilize the journal. See [the focused audit](history-delivery-reconciliation-20261003.md).
Protocol, durable schemas/migrations, native CLI/SDK and transport pins are
unchanged.
