# Explicit native history qualification

This opt-in runner is separate from `npm test`. A command-line flag is an
invocation guard, not authorization: obtain a fresh finite allowance for the
selected native/model work and use disposable state.

```sh
npm run qualify:live -- --allow-live --tool-root=/path/to/toolroot --config-file=/path/to/provider-config.toml --key-file=/path/to/provider-key --provider=selected-provider --model=selected-model
```

Tool and provider inputs are explicit; the framework has no personal home,
provider or model default. Select exactly pinned Codex/Copilot tools from a
read-only tool root. Optional harness/root/child flags can narrow the admitted
scenario; they cannot renew a budget or authorize replay of an admitted prompt.
See [run.mjs](run.mjs) for the actual supported flags and finite bounds.

## Ownership and privacy

A bounded loopback guard selects the supplied provider/model, admits actual
upstream requests before forwarding, and injects credentials only in memory.
Disposable native homes receive a random guard credential. Source configuration
and key files remain unchanged. No fallback provider/model or synthetic model
completion can turn a refused scenario into a pass.

Only exact sessions, processes, containers and directories created by this
invocation may be cleaned up. A timeout does not authorize a replacement prompt
or erase outstanding custody. Observe actual cleanup and preserve a failed
receipt when any required evidence is absent.

The ignored `artifacts/` output contains source/tool manifests, scrubbed bounded
observations, results and checksums. Private native state and raw captures are
not portable evidence. Review and minimize native traces before retaining a
public regression fixture; omit credentials, endpoints, instruction bodies and
ambient native-home information.

## What the seam measures

The runner feeds authoritative native notifications through the actual codec,
Host capture and retained client. Detaching viewers must leave native capture
alive; reconnect converges through retained snapshots. A separate bounded
stored-history audit checks exact native identities and bytes. It is not the
healthy streaming path and must not silently become a resume/getEvents fallback.

Pinned native findings motivate the offline regressions: a command start plus
suffix delta does not prove its output prefix; a positive parent child-activity
edge does not invent a child native context; system instruction/diagnostic
sidebands are not conversation bodies. These rules remain in the codecs and
minimized captured fixtures.

A subset pass does not certify production React/authentication, all callback
variants, native atomic page/live continuity, every child path, full process-tree
containment or the cause of a historical cross-viewer incident. Original Send
receipts, transcript completeness and observed native acknowledgments are
separate evidence. Consult the framework [architecture](../../../../docs/design/v8-architecture.md#qualification)
for those boundaries. Further native/model work always needs fresh explicit
scope; this README grants none.
