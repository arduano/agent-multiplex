# Security boundary

The framework is trusted application infrastructure, not a plugin sandbox.
Authentication, permission checks, exact owner/run identity and input validation
apply at the receiving authority. TypeScript types are not authorization.

Public DTOs exclude credentials, provider configuration and native private homes.
Only a configured Host owns native effects. Gateways observe and route; browser
navigation cannot create, reopen or continue native work. An ambiguous effect
retains its exact original rather than acquiring permission to retry it.

Managed Codex's supplied default is full access with approval on request; owners
can explicitly select another policy. Enabled tool use does not add an invented
approval layer. Native server-requested confirmations must reach an actual user.
Provider selection never silently falls back to another provider or credit path.

This unmerged reconstruction is not a supported production release. Source,
scripted, actual native, browser, transport and installation evidence remain
separate. Report security findings privately to the repository owner.
